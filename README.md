# CoolNavi (クールナビ)

> **「まだ大丈夫」という我慢を、「今、休もう」という行動にするサービス**

CoolNavi は、炎天下の外出時や熱中症の危険がある際に、ユーザーの**現在地（リアルGPS）**から最も近いクーリングシェルター（指定暑熱避難施設）や涼み処をリアルタイムに検索し、**道路網に沿ったターンバイターン歩行者ルート**や**未来型サイバーHUD AR（3D浮遊ピン・ジャイロ地平線・日陰ナビ・クリスタルサウンド）**で迷わず避難誘導するスマートフォン向け次世代Webアプリケーションです。

---

## 🌟 主な新機能と特徴（ハイエンドデザイン＆超高性能）

1. **超美麗グラスモルフィズム & プレミアムデザイン**
   - Appleアプリのような半透明フロストガラス（`backdrop-filter: blur(24px)`）とディープインディゴ・エレクトリックシアンのネオンパレット。
   - 気温、湿度、暑さ指数（WBGT）がリアルタイムに連動するラグジュアリーな気象ウィジェット。
   - 施設ごとの冷却指数（0〜100点）プログレスバーと設備ピル。
2. **リアルタイム現在地オープンデータ動的検索**
   - 静的な固定JSONに依存せず、ユーザーが今いる場所の緯度経度から **OpenStreetMap Overpass API** を直接叩き、半径約2km圏内にある実在の指定避難施設、図書館、公民館、役所、冷房避難スペースをリアルタイム取得。
   - 現在地からの実距離（徒歩2分、徒歩4分など）順に並び替え。
3. **未来的サイバーHUD ARナビゲーション (Turn-by-Turn AR)**
   - 道路網に沿った次の曲がり角（交差点）を指し示すリアルタイム3Dコンパス。
   - 真正面を捉えた瞬間にネオングリーンに発光する**ターゲット・ロックオン演出**。
   - 端末の傾き（ピッチ・ロール）に連動する**ジャイロ地平線インジケーター（Artificial Horizon）**。
   - 街並みの中に立体的に浮かび上がる **3D空間浮遊ピン (AR Floating Pin)**。
4. **太陽位置連動「日陰歩行ナビゲーション」**
   - 現在時刻と緯度経度から太陽の高度と方位角をリアルタイム計算。
   - 「道の左側が建物の日陰です」「正面からの直射日光に注意」といった熱中症対策アドバイスを自動提示。
5. **Web Audio API によるクリスタルサウンド & 触覚ハプティクス**
   - 外部音声ファイル不要。ブラウザ内で直接クリスタルベル音（高周波シンセシス）を生成し、AR起動時やロックオン時、曲がり角接近時に涼やかなサウンドと微小バイブレーションでフィードバック。
6. **CartoDB Positron スタイリッシュベクター地図 (Leaflet)**
   - AppleマップやUberのように視認性の高いホワイト・ベクター調の地図タイル。
   - 3重のシアン・グローパルスアニメーションの現在地ピンと、光彩グロー付きの立体道路ルートライン。
7. **スマートフィルターチップ**
   - 「すべて」「❄️ 強冷房」「💧 給水あり」「🪑 座席多数」「🟢 ゆったり」をワンタップで即時絞り込み。

## 🛠️ 使用技術

- **フロントエンド**: HTML5, CSS3, JavaScript (ES6+ Vanilla JS / 外部フレームワーク不使用)
- **デザイン**: Glassmorphism, Ambient Light Gradients, Neon Cyber HUD
- **地図ライブラリ**: [Leaflet](https://leafletjs.com/) (v1.9.4) + [CartoDB Positron](https://carto.com/)
- **オープンデータ & 公開API**:
  - OpenStreetMap Overpass API (周辺避難施設・クーリングシェルター)
  - Open-Meteo API (リアルタイム気象・湿度・暑さ指数)
  - OSRM (Open Source Routing Machine) (歩行者道路ルーティング)
- **デバイス機能**:
  - Geolocation API (`getCurrentPosition`, `watchPosition`)
  - DeviceOrientation API (`webkitCompassHeading`, 傾きピッチ・ロール検知)
  - MediaDevices API (`getUserMedia` - 背面カメラ)
  - Web Audio API (リアルタイム合成サウンド) & Vibration API

## 🚀 GitHub Pages への公開・スマホでの開き方

VS Code のターミナルで以下を実行してプッシュしてください：

```powershell
git add -A
git commit -m "feat: 超美麗グラスモルフィズムUIと未来型サイバーHUD ARナビへ全面刷新"
git push origin main
```

プッシュ完了後、スマホの Safari で **`https://izawakyo.github.io/coolnavi/`** を開くと、最新のハイエンドデザインと現在地連動ナビがそのまま動作します！
